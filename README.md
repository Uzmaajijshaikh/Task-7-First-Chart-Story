Data Analytics Internship – Task 7 (First Chart Story)

This repository contains my submission for Task 7 of the Data Analytics Internship.

Dataset - Iris Dataset

Objective - The objective was to create simple charts that answer specific questions and communicate the findings through a clear visual narrative.

Tools Used
1. Microsoft Excel 2013
2. Iris Dataset
3. GitHub

Workbook Components
1. Iris Data sheet containing the Iris dataset
2. Chart Analysis sheet containing the summary table, charts, questions, takeaways, and overall narrative

Charts Created
1. Average Petal Length by Iris Species
2. Average Sepal Length by Iris Species
3. Distribution of Iris Species
4. Petal Length vs Petal Width

Analysis Performed
1. Reviewed the Iris dataset and its numerical measurements
2. Calculated average measurements by species
3. Compared average petal length across species
4. Compared average sepal length across species
5. Examined the distribution of observations across species
6. Examined the relationship between petal length and petal width
7. Added a question and one-line takeaway for each chart
8. Created a short narrative connecting the chart findings

Key Findings
1. Iris-virginica has the largest average petal length and sepal length.
2. Iris-setosa has the smallest average petal length and sepal length.
3. Each species has 50 observations in the dataset.
4. Petal length and petal width generally show a positive relationship.

Chart Selection Note - Column charts were used for category comparisons, a pie chart was used to show the distribution of the three Iris species, and a scatter chart was used to show the relationship between petal length and petal width. A line chart was not used because the Iris dataset does not contain a natural time-based or sequential variable.

Files
1. Task 7.xlsx - Excel workbook containing the dataset, analysis, and charts
2. README.md - Summary of the chart story project

Conclusion - The Iris dataset was used to create a simple visual story using Excel. The charts were selected based on the questions they were intended to answer and helped communicate differences and relationships among the three Iris species.
